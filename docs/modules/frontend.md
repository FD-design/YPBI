### 已实现范围

| 入口 | 当前实现 |
|---|---|
| `/login` | YPBI 自有账号登录；登录成功后只允许回到同源安全产品路径，首次登录或管理员重置密码后强制进入改密页 |
| `/data/metrics` | 从 V2 服务端读取指标目录，当前只展示 M016；支持目录刷新、本地关键字搜索、加载/失败/空目录/无搜索结果状态 |
| `/analysis/metrics/M016?pid=...&start=...&end=...` | 单 PID、日粒度真实查询；展示查询上下文、待验数警告、折线图、逐日精确结果表和查询追溯信息 |
| `/admin/data-sources` | 先校验普通账号的维护者角色与 `bi:data-source-maintenance:enter` 权限，再使用独立维护密码建立绑定当前账号和客户端 IP 的二次会话；展示站1/站2脱敏配置，支持测试当前连接、候选 Token 仅验证和验证后保存 |
| `/dashboards/*`、`/analysis/events`、`/analysis/funnels`、`/analysis/saved`、`/data/events` | 只显示“尚未开放”的保留路由页面；没有复用旧页面、Mock 或本地固定数据冒充已实现 |
| 其他未知路径 | 显示页面不存在状态，不自动落入旧功能 |

- `src/main.tsx` 在 production 只加载 V2；经典版仅允许开发环境显式使用 `?ui=v13`，不进入生产构建或公网回退路径。`/dashboards`、`/analysis`、`/data`、`/admin` 及其子路径均由 Product Shell 承载。
- 全局 `AuthProvider` 在渲染产品内容前恢复服务端会话；未登录只显示登录门禁，首次改密用户只显示改密页，普通 401 回到登录页并保留安全回跳路径，403 保留当前身份并显示越权。
- 登录密码、改密字段和候选 Token 都不写入浏览器存储；登录或改密失败后清空全部密码输入。退出、切换账号、会话失效和首次改密成功都会清理敏感状态；窗口重新获得焦点时复核会话，12 小时绝对过期不由前端续期。
- Product Shell 已实现目标一级导航骨架、面包屑、同应用路由、移动端导航开合、Esc/焦点返回、跳到主要内容、键盘可操作账号菜单和退出 / 切换账号。保留导航项只表达目标信息架构，不代表对应业务模块已经实现；维护入口只向具备权限的维护者展示。
- 指标中心只消费服务端目录，不以旧前端数组补指标；M016 分析只消费 V2 指标目录、平台目录与查询响应，不读取旧分析注册表或工作区。
- 浏览器端对指标目录、平台目录、查询成功和错误响应执行严格运行时校验；指标查询还必须逐项核对服务端回显的 `metricId`、`pid`、日期范围和粒度，任何未知字段、缺失日期、重复 / 越界日期、非法状态组合或回显不一致均拒绝展示，不把畸形响应解释成空数据。
- M016 查询条件写入 URL 的 `pid/start/end`，直接打开、刷新以及浏览器前进/后退会按相同条件重新校验身份和查询；默认日期为上海时区下截至昨日的近 7 个业务日，单次范围由 V2 contract 限制为最多 366 日。
- 页面区分首次加载、身份源不可用、未登录、越权、一般失败、目录为空、查询无记录、部分日期不可用和查询成功。无记录/无值在折线中断开并在结果表显示状态，不补成 0；服务端返回的真实 0 正常展示。
- 同一查询条件手动刷新时保留上次成功结果并显示“刷新中”；刷新失败显示旧结果与错误提示。查询条件改变后重新进入首次加载，不把旧条件结果当成新结果。
- 查询追溯区展示 query ID、请求完成时间、数据水位和来源接口；当前水位为空，页面明确显示“暂未提供”，M016 标记“技术称已实现（待验数）”。
- 断网只转换为可重试的服务不可用状态；V2 没有 offline 模式、结果离线缓存、旧工作区读写或跨会话草稿恢复。
- 数据源维护首次进入先检查会话，不闪现登录表单；配置状态与本次会话的凭证探针结果分开，`configured` 不冒充“连接正常”。候选 Token 只保留在当前组件内存且不写入本站浏览器存储；仅验证后保留以便直接继续保存，保存成功、发起退出、刷新、离开或会话失效后清空。保存使用原生模态确认并明确影响站点，服务端仍会重新验证。
- 维护客户端单独校验遗留管理 API 响应；响应一旦包含未声明字段（包括原始 Token）、非固定掩码或配置状态矛盾即拒绝展示。保存只有收到明确成功结果才显示已生效；断网、超时或畸形响应显示“结果未确认”并要求核对。退出失败不伪装成已退出。PID 路由具体范围和跨会话检测历史尚无接口支持，页面如实显示由服务器管理，不硬编码平台清单。
- 除受保护的数据源 Token 更新外，当前切片没有看板、事件、漏斗、个人保存、导出、比较或卡片编辑写入。

### 工作台精简规则

- 工作台只保留一条全局主导航，不再并排显示第二条纵向模型侧栏。
- 分析模型改为内容区顶部横向选择条，集中显示名称和接口状态；当前模型说明只展示一次。
- 当前模型说明在中间区域展示。
- 接口路径与能力限制默认折叠。
- 右侧仅保留卡片名称、分析说明、漏斗字段和一张主预览。
- 保存按钮只保留一个，避免重复动作。
- 卡片库按图表类型折叠并支持类型筛选；卡片库和模板编辑器中的缩略图明确标注为“示例数据结构预览”，不冒充实时结果。
- 卡片库保留 12 种系统图表类型，并按能力标记“真实直接统计”“真实聚合计算”或“汇总近似”。旧浏览器缓存会保留用户卡片，同时自动补入新增系统卡片。
- 平台日期热力图、平台贡献瀑布图、平台贡献矩形图及内容/支付汇总桑基图作为可选卡片资产提供，不强行加入默认看板，避免首屏增加重复的全平台查询。

### 卡片平台范围与完整预览

- 顶部平台筛选是看板默认范围；卡片可保存独立的全部平台、单平台或 2–8 平台对比范围。
- 卡片标记必须展示实际范围来源，独立配置优先于顶部看板筛选。
- “完整预览”放大当前卡片，保留趋势、变化和表格视图，并允许临时切换平台范围；临时范围不自动覆盖已保存配置。
- 卡片编辑抽屉中的平台配置随模板工作区持久化，旧卡片默认跟随看板。
- 所有卡片标题栏均直接显示实际平台范围与完整预览入口；完整预览展示指标/维度中文口径、接口路径、聚合算法、公式、数据粒度和能力边界。
- 当前周期与对比周期统一显示 `↑/↓/→`、变化百分比和对比期数值；颜色依据指标正负含义，而箭头仅表示数值方向。
- 所有字段 `?` 为可点击说明按钮，统一弹窗显示中文定义、算法/公式、接口、粒度和能力边界；不再仅使用原生悬停提示。
- 指标说明使用独立的指标级口径字典，禁止以技术公式代替中文定义，也禁止直接展示模型的全部接口作为单个指标来源。
- “变化”只展示周期分析结论；“查看明细”使用独立按钮打开右侧下钻抽屉，图表节点点击仍可直接定位节点明细。
- 创建和编辑卡片时，指标按规模、终端、来源、广告、内容与观看、付费、留存等分组，并支持中文名称和字段 ID 搜索。
- 系统模板读取旧工作区时同步内置卡片的最新指标和图表配置，同时保留用户已保存的卡片宽度和独立平台范围；用户自建模板不自动改写。

### 数据状态

- 加载：显示明确的卡片级加载状态。
- 卡片查询：卡片顶部显示平滑进度条，状态文字同步显示模拟进度百分比；请求完成后补满至 100% 并淡出。该百分比表示等待进度，不冒充服务端真实处理比例。
- 页面查询：渠道、分类和专项页面的加载区域显示同风格流动进度轨道；减少动态效果模式下关闭循环动画。
- 顶部查询健康状态汇总加载中数量、异常数量、最近成功时间和单卡查询耗时。
- 查询失败：保留该卡片上次成功结果，并提供卡片级重试，避免短时异常清空整张图。
- 空数据：显示真实空态，不生成 Mock。
- 留存看板展示 D1、D3、D7、D30；未达到对应观察日的 cohort 显示“—”，不按 `0` 参与汇总。
- 全部平台模式下，接口未返回记录的平台以占位 `0` 补齐，并在卡片标题区显示覆盖数量；“暂无记录”与接口明确返回的真实 `0` 分开解释。
- 统计表的维度和指标列统一显示中文名称，内部字段 ID 只用于查询与计算。
- 配置不支持：阻止查询并提示进入卡片工厂调整。
- 接口错误：显示真实错误，不吞掉 401、403、429、超时和上游 500。
