## 2026-08-03 三种周期对比模式

- 日期筛选新增自然月、等长周期、同期进度三种自动对比模式。
- 自然月：当前周期结束日所在月份，对比上一个完整自然月；允许 31 天与 30/28/29 天比较，日均指标直接可比。
- 等长周期：使用当前周期之前紧邻的相同天数，适合收入、新增、次数等累计指标严格比较。
- 同期进度：对比上月 1 日至相同日序，适合月中经营进度比较。
- 对比周期由系统根据当前周期自动生成并展示天数，避免手工选错；旧筛选配置默认兼容为等长周期。

## 核心交互

- 全局筛选：顶部统一控制全部 20 平台、单平台、最多 8 平台对比，以及今日、近 7 日、近 30 日和自定义起止日期。
- 平台筛选：在弹层内先选择汇总、单平台或 2–8 平台对比，再统一应用；取消不会触发查询或修改当前范围。
- 日期筛选：快捷范围可直接应用；自定义范围按自然日选择开始和结束日期，包含首尾两天，并校验开始日期不晚于结束日期。
- 时间对比：每次查询同时包含当前周期和对比周期；快捷范围自动使用等长前置周期，自定义时可分别选择两段日期，且要求天数一致。
- 对比展示：指标卡显示对比期数值和变化率；趋势图追加“对比期”系列；分析摘要明确列出两段日期。
- 分类、渠道和专项系统模板已改为继承完整平台范围：全部模式查询 20 个平台，对比模式查询所选 2–8 个平台，单平台模式只查询当前平台。
- 字段解释：指标卡、统计表头和分析配置字段均带 `?` 提示；悬停或键盘聚焦可查看字段来源、公式或口径。
- 图表视图：趋势、变化分析、数据表格。
- 下钻：点击图表节点打开右侧抽屉，查询真实用户或圈子明细。
- 表格：分页，不在主看板堆叠长明细。
- 卡片创建：指标、维度和图表选项由 API 能力表约束。
- 分析条件：查询筛选器、拆分维度和统计指标均可直接点选；非漏斗模型统一修改右侧正在预览的主卡片，选择后实时刷新图表。
- 选择反馈：已选字段显示勾选和高亮；指标、拆分维度至少保留一项，查询筛选器允许按需启用或关闭。
- 漏斗创建：点击或拖动已开放事件，支持排序和删除。
- 模板创建：卡片拖至当前位置插入；新增卡片默认进入顶部。
- 模板编辑器默认只保留模板列表和全宽画布；卡片库通过“添加卡片”按需从右侧打开，不再作为常驻第三栏挤压图表。
- 卡片库抽屉内支持类型筛选、结构预览和新建卡片；卡片可拖到画布插入线指定的位置，也可直接添加到模板顶部，关闭抽屉不影响未保存草稿。
- 卡片库抽屉按动态视口高度占满可用区域，卡片列表独立占据剩余空间并滚动；低高度屏幕自动隐藏示例预览，保留筛选和卡片操作空间。
- 窄屏抽屉宽度使用响应式范围，滚动条提供更大的可视与拖动区域，并增加底部安全留白，避免被浏览器或会议工具栏遮挡。
- 模板管理进入独立编辑状态，不显示业务平台和日期筛选，也不显示一级工作区导航；返回后恢复日常看板模式。
- 预览、取消、保存、保存并发布和添加卡片统一放在模板顶部工具栏；模板属性区只配置名称、场景、模型和公共筛选器。
- 卡片编辑、上移、下移和移除工具默认隐藏，悬停、键盘聚焦或选中卡片后才显示，减少画布噪音。
- 模板编辑：所有修改先保留在编辑器草稿中，点击“保存模板”或“保存并发布”后才写入工作区；“取消修改”恢复最近保存版本。
- 模板预览：预览保持在模板编辑器内，不切换到看板中心；工具栏提供返回编辑、取消修改、保存模板和保存并发布。
- 卡片资产：支持复制；分析工作台支持最多 20 步撤销，保存前继续执行 API 能力校验。
- 字段配置：卡片编辑抽屉、分析工作台和模板内配置统一读取真实 API 能力白名单，不再从 Mock 模型元数据暴露越界字段。
- 卡片宽度：看板中心和模板编辑器支持拖动卡片右侧边缘，宽度按 12 列网格吸附为半宽、2/3 宽或整行。
- 布局保存：看板中心先本地预览，点击“保存布局”后写入当前模板；模板编辑器调整后同样通过“保存布局”确认，随后由工作区 API 持久化。
- 键盘操作：宽度手柄聚焦后可使用左右方向键逐档调整；移动端保持整行展示，不显示拖动手柄。

## 看板阅读模式

- 看板中心只保留一条主导航和一块全宽内容区，不再长期占用二级模板侧栏。
- 看板模板通过标题上方的紧凑选择器切换。
- 卡片悬停时仅在右侧边缘显示宽度手柄，调整期间显示蓝色焦点框，未修改时保存按钮禁用。
- 卡片默认只展示标题、分析模型、查询状态和关键指标；日期、平台范围及数据粒度放入查询状态提示。
- 桌面端优先展示趋势与平台差异；移动端核心 KPI 使用 2×2 布局，图表卡片依次纵向排列。
- 经营、内容、搜索、支付和留存看板分别展示三项阅读重点，内容是分析方向提示，不冒充真实结论。
- 平台排行按核心指标降序，并始终展示当前筛选范围内的全部平台；超过 10 行时自动增加图表高度，不用 Top N 截断数据。
- 平台气泡矩阵保留全部平台点位，半宽卡片常显 DAU 前 3、较宽卡片常显前 5；其余平台通过悬浮查看，避免标签遮挡。
- 全平台趋势使用可滚动图例容纳 20 个平台系列；瀑布图、热力图、Cohort 和贡献矩形图同样不得省略当前范围内的平台。
- ECharts 悬浮详情挂载到页面 `body`，不受卡片圆角和 `overflow` 裁切；20 平台 Tooltip 限制在视口 70% 高度内并支持滚动查看全部平台。
- 顶部标题、说明和筛选控件使用自适应高度与明确行高，文字不得被固定顶栏裁切。
- KPI 在没有对比周期时只标记“当前区间”，不显示“较上期”。

## 卡片平台范围与完整预览

- 顶部平台筛选是看板默认范围；卡片可保存独立的全部平台、单平台或 2–8 平台对比范围。
- 卡片标记必须展示实际范围来源，独立配置优先于顶部看板筛选。
- “完整预览”放大当前卡片，保留趋势、变化和表格视图，并允许临时切换平台范围；临时范围不自动覆盖已保存配置。
- 卡片编辑抽屉中的平台配置随模板工作区持久化，旧卡片默认跟随看板。
- 所有卡片标题栏均直接显示实际平台范围与完整预览入口；完整预览展示指标/维度中文口径、接口路径、聚合算法、公式、数据粒度和能力边界。
- 当前周期与对比周期统一显示 `↑/↓/→`、变化百分比和对比期数值；颜色依据指标正负含义，而箭头仅表示数值方向。
- 所有字段 `?` 为可点击说明按钮，统一弹窗显示中文定义、算法/公式、接口、粒度和能力边界；不再仅使用原生悬停提示。
- 指标说明使用独立的指标级口径字典，禁止以技术公式代替中文定义，也禁止直接展示模型的全部接口作为单个指标来源。
- “变化”只展示周期分析结论；“查看明细”使用独立按钮打开右侧下钻抽屉，图表节点点击仍可直接定位节点明细。
- 创建和编辑卡片时，指标按规模、终端、来源、广告、内容与观看、付费、留存等分组，并支持中文名称和字段 ID 搜索。
- 系统模板读取旧工作区时同步内置卡片的最新指标和图表配置，同时保留用户已保存的卡片宽度和独立平台范围；用户自建模板不自动改写。

## 数据状态

- 加载：显示明确的卡片级加载状态。
- 卡片查询：卡片顶部显示平滑进度条，状态文字同步显示模拟进度百分比；请求完成后补满至 100% 并淡出。该百分比表示等待进度，不冒充服务端真实处理比例。
- 页面查询：渠道、分类和专项页面的加载区域显示同风格流动进度轨道；减少动态效果模式下关闭循环动画。
- 顶部查询健康状态汇总加载中数量、异常数量、最近成功时间和单卡查询耗时。
- 查询失败：保留该卡片上次成功结果，并提供卡片级重试，避免短时异常清空整张图。
- 空数据：显示真实空态，不生成 Mock。
- 留存看板展示 D1、D3、D7、D30；未达到对应观察日的 cohort 显示“—”，不按 `0` 参与汇总。
- 全部平台模式下，接口未返回记录的平台以占位 `0` 补齐，并在卡片标题区显示覆盖数量；“暂无记录”与接口明确返回的真实 `0` 分开解释。
- 统计表的维度和指标列统一显示中文名称，内部字段 ID 只用于查询与计算。
- 配置不支持：阻止查询并提示进入卡片工厂调整。
- 接口错误：显示真实错误，不吞掉 401、403、429、超时和上游 500。
