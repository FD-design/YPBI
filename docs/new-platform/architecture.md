# 独立产品 BI 平台架构

> 状态：本地真实数据接入完成。首个产品为 NewAV，后续产品通过注册表和独立 Adapter 接入，不与原 20 平台 BI 混用。

## 运行边界

- 代码目录：`new-platform/`
- 前端端口：`5190`
- API 端口：`3100`
- 数据源变量：`NEWAV_API_BASE_URL`、`NEWAV_ACCESS_TOKEN`
- 原 BI 的 PID、`x-token`、站 1/站 2路由、模板和工作区文件均不读取。
- 不配置 Token 时显示真实配置错误，不使用 Mock 数据冒充业务结果。

## 产品扩展结构

| 层级 | 代码 | 职责 |
|---|---|---|
| 产品注册 | `server/products.ts` | 登记产品 ID、名称、状态和数据源类型 |
| 数据目录 | `server/newav/catalog.ts` | 登记 12 个可调用数据集及参数能力 |
| 请求客户端 | `server/newav/client.ts` | Bearer 鉴权、超时、有界缓存和错误映射 |
| 数据 Adapter | `server/newav/adapter.ts` | 原始响应归一化、自然日/渠道粒度和加权计算 |
| 查询 API | `server/app.ts` | 产品校验、日期校验、统一响应和状态查询 |
| 产品工作区 | `src/main.tsx` | 看板、卡片库、模板中心、数据源和产品切换 |

新增产品时建立独立目录 `server/<product>/`，实现目录、客户端和 Adapter，再加入产品注册表。每个产品拥有自己的指标、卡片和模板，不进入 NewAV 或原 BI 的汇总口径。

## 当前功能

- 产品切换入口和“添加产品”扩展位。
- 看板中心：经营总览、渠道增长、收入与续费、广告表现。
- 卡片库：查看可复用分析卡片。
- 模板中心：模板切换、编辑排序和浏览器本地持久化。
- 数据源：展示 NewAV 地址、Bearer 鉴权状态和 12 个接口数量。
- 真实查询：`POST /api/query`，支持日期区间和渠道参数。
- 明确日均、累计人天和加权比例，不把跨日 UV 直接描述为周期去重人数。
